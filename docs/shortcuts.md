# 快捷键

在 Windows 和 Linux 的浏览器里，把 ⌘ 换成 Ctrl。

## 文件

| 操作 | 快捷键 |
| :-- | :-- |
| 新建 | ⌘N |
| 新建窗口 | ⇧⌘N |
| 打开 | ⌘O |
| 快速打开 | ⇧⌘O |
| 重新打开关闭的文件 | ⇧⌘T |
| 保存 | ⌘S |
| 另存为 | ⇧⌘S |
| 全部保存 | ⌥⌘S |
| 打印 | ⌘P |
| 偏好设置 | ⌘, |

## 自定义快捷键

在 设置 → 通用 → 打开高级设置 里编辑 `conf.user.json`，在 `keyBinding` 里按菜单的英文名称或命令 id 写上新的快捷键，重新打开窗口后生效。留空字符串表示去掉这个快捷键。

```json
{
  "keyBinding": {
    "Code Fences": "ctrl+shift+k",
    "Always on Top": "ctrl+cmd+t"
  }
}
```
