# Change Log

## 0.4

**Editing**

- Emoji autocomplete: type `:` and a few letters.
- Smart quotes and dashes can convert while typing or only on screen.
- Upper case, lower case and capitalize under **Edit → Transformations**.
- Shift+Tab outdents code, or re-indents it; indent size is configurable.
- Default language for new code fences.
- Copy or cut the whole line when nothing is selected (optional).
- Footnote and link definitions can go to the end of the document, section or block.
- ` ```math ` code blocks, the physics macros, AMS-style equation numbering.
- Strict mode, heading style and list marker preferences.

**Files**

- TextBundle documents.
- Reopen Closed File, Save All, Revert to Saved.
- File tree: hidden files, all file types, glob patterns, pinned folders, eight sort orders, grouping by folder, a name filter, Quick Look.
- What to do with dropped files and folders; default file extension.

**Images**

- Insert several local images at once; take a picture with an iPhone or iPad.
- Copy, rename, move or delete the image file under the caret.
- Per-document image folder and image root path in the front matter.
- PicGo, PicList and uPic uploaders, with a test button; online images can be downloaded on paste.

**Export**

- PDF: more paper sizes, a margin per side, header and footer, bookmarks, page breaks before top-level headings.
- HTML: extra content for `<head>` and `<body>`.
- JPEG image export.
- Pandoc path and options, your own export formats, a command to run after export.

**Window**

- Gothic theme, editor toolbar, Unibody window style, Touch Bar, Custom CSS.
- Zoom with the mouse wheel; magnification.
- Custom shortcut keys.

## 0.3

- Native Mac app with tabs, sharing, printing and PDF export.
- English and Simplified Chinese interface.
- Chinese, Japanese and Korean input methods.
